# 相続管理アプリ

相続税申告のための統合管理アプリです。1つのHTMLファイル（`index.html`）で完結し、Chromeブラウザで動作します。相続開始時の打合せから、必要資料の確認、相続財産一覧の作成、遺産分割協議書の作成までを **被相続人ごと** に管理できます。

## 主な機能

| ステップ | 画面 | 内容 |
|---|---|---|
| 1 | 基本情報・打合せ | 被相続人情報、相続人情報、申告期限/準確定申告期限の自動計算、打合せメモ、委任契約書の作成 |
| 2 | 必要資料 | 資料チェックリスト（必要/不要/受領済/一部受領済）、PDF・Excel出力 |
| 3 | 財産一覧 | 財産を種別ごとに登録、課税価格・基礎控除の概算を自動集計 |
| 4 | 遺産分割協議書 | 各財産の取得者を割り当て、遺産分割協議書を自動作成 |
| ― | 設定 | Googleドライブ連携、ローカルバックアップ |

### 管理できる財産種別
土地 / 建物 / 有価証券 / 非上場株式 / 現金・預貯金 / 生命保険金等 / 退職手当金等 / その他の財産 / 債務 / 葬式費用 / 生前贈与財産

## データの保存（Googleドライブ）

- 「設定」画面で **保存先フォルダのURL** を貼り付けると、そのフォルダに案件データ（JSONファイル）が保存されます。
- 被相続人ごとに `相続案件_〇〇.json` という1ファイルで保存され、「保存」を押すたびに上書き更新されます。
- 次回はログイン後「Driveから一覧取得」で案件を読み込み、**続きから** 作業できます。
- バックアップとしてブラウザのローカル（localStorage）にも自動保存され、JSONファイルの手動エクスポート/インポートも可能です。

## 起動方法（重要）

Googleログイン（OAuth）はセキュリティ仕様上 `file://`（ファイルをダブルクリックして開く方法）では動作しません。**`http://localhost` 経由で開いてください。**

このフォルダで簡易サーバーを起動する例：

```bash
# Python がある場合
python -m http.server 8000

# Node.js がある場合
npx serve .
```

起動後、Chromeで `http://localhost:8000` を開きます。

> Googleドライブ連携を使わず、ローカルのバックアップ（JSONエクスポート/インポート）だけで使う場合は、`file://`（ダブルクリック）でも動作します。

## 初回セットアップ

1. `http://localhost` でアプリを開く
2. 「設定」→ 保存先フォルダURLを入力
3. 必要に応じて OAuth クライアントID を自分のものに変更（初期値あり）
4. 「Googleでログイン」→「接続をテスト」で確認
5. 「案件一覧」→「＋ 新規案件」で開始

### OAuth クライアントIDについて
初期値が設定済みですが、ご自身の環境（localhostのポート等）に合わせて Google Cloud Console で発行したクライアントIDに変更できます。承認済みJavaScript生成元に、利用するURL（例：`http://localhost:8000`）を登録してください。

## ご注意

- 課税価格・基礎控除の表示は **概算** です。正式な税額計算ではありません。最終的な判断は必ず税理士等の専門家が行ってください。
- 法定相続人数は入力された相続人の人数で概算しています。
