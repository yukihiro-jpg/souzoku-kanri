# 相続管理アプリ

相続税申告のための統合管理アプリです。1つのHTMLファイル（`index.html`）で完結し、Chromeブラウザで動作します。相続開始時の打合せから、必要資料の確認、相続財産一覧の作成、遺産分割協議書の作成までを **被相続人ごと** に管理できます。

## 主な機能

| ステップ | 画面 | 内容 |
|---|---|---|
| 1 | 基本情報・打合せ | 被相続人情報、相続人情報、申告期限/準確定申告期限の自動計算、打合せメモ、委任契約書の作成 |
| 2 | 必要資料 | 資料チェックリスト（必要/不要/受領済/一部受領済）、PDF・Excel出力 |
| 3 | 財産一覧 | 左メニューの財産種別サブメニューから種別ごとの詳細画面へ。**1財産=1行**で財産評価明細書相当の項目を入力（土地＝路線価×面積／固定資産税評価額×倍率×所有権割合×調整、建物・有価証券＝単価×数量 等を自動計算） |
| 4 | 遺産分割 | **種類順→明細でグルーピング**した一覧で、相続人ごとの取得額を入力（1人目は評価額−他の相続人で自動算出）。種別小計・合計を表示。遺産分割協議書を自動作成 |
| 5 | 相続税試算 | 遺産分割に基づき、相続税法（現行法）に従って相続税額を計算 |
| ― | 設定 | Googleドライブ連携、ローカルバックアップ |

### 相続税試算について（ステップ5）
相続税法の本則どおりに計算します：各人の課税価格（1,000円未満切捨て）→ 課税価格の合計額 → 基礎控除（3,000万円＋600万円×法定相続人数）→ 課税遺産総額 → 法定相続分で按分し速算表を適用して **相続税の総額** → 各人の課税価格割合で按分 → 2割加算・各種税額控除。

**反映している規定:**
- **法定相続人の数**：相続放棄を「なかったもの」として算入。**養子の数の制限**（実子がいれば1人、いなければ2人まで）を適用。
- **代襲相続**：法定相続分を株分け（同じ被代襲者の代襲相続人は1株を分け合う）。「代襲元グループ」で指定。
- **小規模宅地等の特例**：特定居住用(330㎡/80%)・特定事業用(400㎡/80%)・特定同族会社事業用(400㎡/80%)・貸付事業用(200㎡/50%)。限度面積と貸付併用時の調整を反映（財産一覧の各土地⚙で設定）。
- **生命保険金・退職手当金の非課税**（500万円×法定相続人数）。
- **生前贈与加算**：暦年課税（3年超7年以内分の合計100万円控除に対応）・相続時精算課税。
- **税額控除**：贈与税額控除（暦年／精算課税、精算課税の控除不足は還付）、配偶者の税額軽減（1.6億円／法定相続分の上限調整）、未成年者控除・障害者控除（引ききれない額は扶養義務者へ移転）、相次相続控除。

相続人の「続柄区分・実子/養子・代襲・相続放棄・年齢・障害者区分」を基本情報画面で設定します。

**対象外:** 納税猶予（事業承継税制・農地等）、外国税額控除、半血兄弟姉妹の相続分調整、小規模宅地の限度面積の最適自動選択、各特例の適用要件の自動判定。最終的な申告は必ず税理士がご確認ください。

### 管理できる財産種別
土地 / 建物 / 有価証券 / 非上場株式 / 現金・預貯金 / 生命保険金等 / 退職手当金等 / その他の財産 / 債務 / 葬式費用 / 生前贈与財産

## データの保存（Googleドライブ）

- 「設定」画面で **保存先フォルダのURL** を貼り付けると、そのフォルダに案件データ（JSONファイル）が保存されます。
- 被相続人ごとに `相続案件_〇〇.json` という1ファイルで保存され、「保存」を押すたびに上書き更新されます。
- 次回はログイン後「Driveから一覧取得」で案件を読み込み、**続きから** 作業できます。
- バックアップとしてブラウザのローカル（localStorage）にも自動保存され、JSONファイルの手動エクスポート/インポートも可能です。

## 起動方法（重要）

Googleログイン（OAuth）はセキュリティ仕様上 `file://`（ファイルをダブルクリックして開く方法）では動作しません。**`http://localhost` 経由で開いてください。**

このフォルダで簡易サーバーを起動する例：

```bash
# Python がある場合
python -m http.server 8000

# Node.js がある場合
npx serve .
```

起動後、Chromeで `http://localhost:8000` を開きます。

> Googleドライブ連携を使わず、ローカルのバックアップ（JSONエクスポート/インポート）だけで使う場合は、`file://`（ダブルクリック）でも動作します。

## 初回セットアップ

1. `http://localhost` でアプリを開く
2. 「設定」→ 保存先フォルダURLを入力
3. 必要に応じて OAuth クライアントID を自分のものに変更（初期値あり）
4. 「Googleでログイン」→「接続をテスト」で確認
5. 「案件一覧」→「＋ 新規案件」で開始

### OAuth クライアントIDについて
初期値が設定済みですが、ご自身の環境（localhostのポート等）に合わせて Google Cloud Console で発行したクライアントIDに変更できます。承認済みJavaScript生成元に、利用するURL（例：`http://localhost:8000`）を登録してください。

## ご注意

- 課税価格・基礎控除の表示は **概算** です。正式な税額計算ではありません。最終的な判断は必ず税理士等の専門家が行ってください。
- 法定相続人数は入力された相続人の人数で概算しています。

## 有価証券の株価自動取得（CORS対策）

ブラウザから株価APIを直接呼ぶとCORSで失敗するため、設定の「株価の自動取得」で取得方法を選べます。

- **Stooq（既定・設定不要）**：CORS許可済みのため追加設定なしで株価4時点を取得できます（日本株は `7203` のように入力、内部で `7203.jp` に変換）。配当データは取得しないため、未収配当金・配当期待権は手入力してください。
- **Google Apps Script（推奨・配当も取得）**：自分のGoogleアカウントでGASウェブアプリを発行し、そのURLを設定に貼ると、サーバー側でYahoo!ファイナンスを取得して返します（CORS回避・第三者を経由しない）。配当データも取得できます。設定画面に貼り付けるコードを表示しています（`doGet` で `UrlFetchApp.fetch`）。デプロイは「ウェブアプリ／アクセス：全員」。
- **公開CORSプロキシ**：手軽ですが混雑・仕様変更で失敗することがあります。

いずれの方法でも、取得が不調な場合は4時点の価格・配当を手入力でき、評価額は自動計算されます。
